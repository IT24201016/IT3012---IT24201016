# IT3012 Practical 01 — Agent–Environment Architecture

Completed Practical 01 includes the official starter code and the toxic-trap
extension in `visual_grid_game.py`.

## Run the visual simulation

```bash
python visual_grid_game.py
```

Purple diamonds are toxic traps. Entering one deducts 15 points.

## Run the Practical 01 tests

```bash
python -m unittest -v test_lab_01.py
```
